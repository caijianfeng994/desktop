# Phase 1 硬件采购与部署清单

预算目标：≤ ¥500。

## 采购

| 模块 | 选型 | 预算 |
|------|------|------|
| 主控 | 二手 Pi Zero 2W / 香橙派 Zero 等 | ¥80–180 |
| TF | 32GB 正规卡 | ¥20–35 |
| 屏 | 2.4"–3.5" SPI/HDMI | ¥40–90 |
| 语音 | USB 麦喇叭 | ¥30–70 |
| 舵机 | SG90×2 + 云台支架 | ¥20–40 |
| 供电 | 5V≥3A | ¥25–40 |
| 结构 | 纸板/亚克力/3D 打印 | ¥20–50 |

优先保证麦/喇叭与供电。

## 部署

1. 刷 Linux，安装 Python 3.11+。
2. 克隆本仓库，`pip install -e ".[dev]"`。
3. 先用 `--body fake` 验证 Brain；再接本地 GPIO Body（后续 `body/local_gpio.py`）或继续小智桥。
4. 数据目录：`./data/robot.db`。
