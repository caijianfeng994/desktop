# 小小工坊：玩家自主设计与机械装配玩法方案

日期：2026-09-24  
状态：产品设计提案；**阶段 0 已落地，阶段 1（空机架 / 连接预览 / 首批参数）已开始实施**。本文其余阶段（驱动绑定、自制组件、探索关卡）尚未实施，不将建议视为现有能力。

## 1. 核心问题与方向

用户反馈：游戏“不立体、不刺激、没有追求”，装配“不专业，没有让玩家自己设计、自己组装”。

当前固定零件切换、成品机械臂和模板应用难以形成作品归属感。专业感应来自结构有依据、连接有规则、动作有因果、失败能解释。玩家需要决定机器的形状、连接、驱动与控制，并用自己的设计解决空间挑战。

产品方向：**自己设计机器人，征服巨大的房间。** 工坊承担设计、组装、试验和收藏；房间承担探索、操作挑战与新能力的使用。定位为容易上手的机械创造游戏，工程级仿真精度和实际可制造性不属于本提案默认承诺。

核心循环：发现障碍 → 提出设计 → 组装机器 → 试跑诊断 → 修改 → 完成挑战 → 获得新能力与探索目标。

## 2. 玩家拥有的设计权

| 设计内容 | 玩家操作 | 需要产生的结果 |
| --- | --- | --- |
| 机架与外形 | 从空机架开始，选择底板、梁、支架，调整尺寸、位置与角度 | 外形与占地、重量、通行能力对应 |
| 装配连接 | 选择安装面、孔位、轴或插槽，确认连接预览 | 零件按可解释的规则连接，不只是任意悬浮摆放 |
| 运动结构 | 安装电机、轮轴、转动关节和伸缩机构 | 不同结构产生不同运动能力 |
| 末端工具 | 用关节、连杆、夹指等组成工具 | 工具的开口、可达范围与方向影响操作 |
| 控制方式 | 绑定按键、设置方向、速度与限位，配置联动 | 玩家能操控自己设计的机构 |
| 结构改进 | 查看碰撞、重心、限位与驱动反馈 | 失败后能作出有依据的修改 |

模板只是可完全拆解、修改的教学示例。自由设计入口不得强制玩家使用成品底盘或整条机械臂。

## 3. 零件与组件体系

### 基础件

- 结构件：底板、梁、立柱、支架、配重。
- 运动件：轴、轴承座、轮子、转动关节、滑动关节。
- 驱动件：电机与伸缩驱动模块。
- 工具件：夹指、推板、钩子与连接件。
- 功能件：电池、摄像头、显示模块。

首版只为必要参数开放编辑，例如梁长、板宽、安装角度、关节范围。参数需要上下限和碰撞校验；自由度逐步开放，避免不可解释的无效结构。

### 玩家自制组件

玩家可将选定的连通结构保存为“我的机械臂”“我的底盘”等组件，定义对外连接口和控制入口。组件可重复实例化、再次拆开编辑。修改一个实例默认不改变其他作品；更新组件定义时需明确版本与影响范围。

自由设计模式直接提供基础件，允许不消耗货币地试验。冒险模式逐步解锁新机制和高级零件，以探索目标引导设计，避免在开始创造前设置大量资源门槛。

## 4. 三维装配工作台

画布为主要操作区域，零件库和参数面板围绕画布展开。窄窗口仍需同时看见选中的零件和连接位置。

必要操作：

1. 新建空作品，选择核心或基础机架。
2. 从零件库选择零件，显示半透明预览与可兼容连接点。
3. 吸附、旋转、调整尺寸并确认安装；不兼容时解释原因。
4. 点击模型选中零件，在属性面板调整参数。
5. 支持复制、镜像、拆卸、删除、撤销与重做。
6. 保存作品、另存副本，以及将局部结构保存为自制组件。

辅助视图：尺寸与角度、连接树、正交视图、局部剖视、外壳隐藏和爆炸视图。展示辅助不改变实际蓝图位姿。默认隐藏复杂参数，需要时再展开。

首版使用标准连接面、离散孔位和轴线吸附，不要求实现完整 CAD 草图约束求解器。固定结构可合并模拟；活动部分按关节分离。闭环连杆等复杂机构应在支持约束求解后再开放，不能让界面声称可装而运行无法支持。

## 5. 驱动与控制设计

每个可驱动部件显示作用轴、正反方向、运动范围与当前状态。玩家可绑定驾驶、转向、抬臂、伸出和夹取操作；同一输入可控制多个部件，并为各部件设置方向与比例。

首版优先直接按键控制和简单联动，不引入必须编程才能启动的门槛。两指夹爪可通过两根滑动轴或转轴配合反向联动实现，无需一开始就模拟复杂齿轮传动。

推荐控制映射必须可编辑。发生按键冲突、关节无驱动或控制目标缺失时，在试跑前显示可修复的问题。

## 6. 最小完整体验：亲手造一条机械臂

目标：不用成品机械臂模板，让玩家造出能够抬起、伸出并夹住物体的机械臂。

建议教学路径：

1. 搭建底盘，自选轮数与轮距。
2. 安装立柱、电机和肩部转轴。
3. 用两段梁和肘部转轴形成可伸展的手臂。
4. 安装夹指和夹取驱动，配置开合联动。
5. 设置限位、方向，并绑定抬臂和夹取操作。
6. 试跑取物；若前倾，尝试加宽底盘、缩短手臂或移动电池作配重。
7. 保存作品，再将机械臂单独保存为组件。

教学每次只引入一个概念，允许跳过和自由探索。任务不检查是否照抄指定模板，而检查机器是否真正完成动作与目标。

## 7. 真实反馈与快速试错

至少实现三类可感知的取舍：

| 改装 | 收益 | 代价 |
| --- | --- | --- |
| 加长手臂 | 扩大可达范围 | 更容易前倾，驱动负担增加 |
| 加宽底盘 | 改善稳定性 | 无法通过部分窄缝 |
| 增加配重 | 改善特定姿态下的平衡 | 总重量增加，移动或抬升更困难 |

失败提示应指向原因，例如“重心超出支撑范围”“关节到达限位”“工具未接触目标”“驱动力不足”。可切换查看重心、支撑区域、碰撞和运动范围。

试跑可暂停、复位和返回编辑。作品草稿、已保存版本与运行快照分离；普通点击不能触发重新载入并覆盖草稿。保存不能无故清空撤销历史。首先解决第三轮试玩发现的模板丢失与工具不一致问题，再扩展功能。

## 8. 用空间冒险建立追求

立体感来自高度、尺度和路径选择：跨桌缝、攀爬书架、悬挂取物、升降和高处搬运。镜头需要支持跟随、缩放与聚焦，让玩家看清机构和落点。

紧张感来自可以预判的风险：失稳、滑落、移动障碍和限时救援。失败应快速重试，不以丢失作品或长时间重复劳动惩罚玩家。

成长目标分三层：

- 短期：用当前设计完成一次抓取、跨越或救援。
- 中期：获得新机制，造出攀爬机、绞盘车等不同机器。
- 长期：从书桌探索到地板、柜顶和窗台，找回伙伴并扩建工坊。

这些区域与能力属于远期方向，不纳入首版机械臂原型的必做范围。

候选验证关卡为“跨桌缝救援”：提供斜坡、移动障碍、桌缝和被困伙伴，探索搭桥、绞盘或推进跳跃等路线。应在基础装配与运动稳定后分步实现，不同时堆入全部机制。

## 9. 分阶段实施

| 阶段 | 交付重点 | 完成条件 |
| --- | --- | --- |
| 0：可靠性 | 修复草稿覆盖、保存与试验场不同步 | 编辑、保存、刷新和试跑中的结构一致 |
| 1：自主设计 | 空机架、基础件、连接预览、参数、撤销与保存 | 玩家能不用模板搭出不同结构 |
| 2：自主控制 | 驱动配置、按键绑定、夹指联动、限位 | 自制机械臂可抬起、伸展、夹取与释放 |
| 3：结构反馈 | 质量、稳定性、可达范围、诊断与复位 | 修改结构能解决一次真实失败 |
| 4：探索追求 | 一个有高度与风险的多解挑战 | 玩家愿意换设计再试，并期待新区域 |

不在本提案中承诺固定开发周期。各阶段以可试玩验收结果推进，避免只以文件、模块或按钮数量判断完成。

## 10. 验收清单

- [ ] 从空机架开始，不使用成品机械臂也能完成取物。
- [ ] 同一种基础件可重复使用，每个实例独立编辑。
- [ ] 连接与运动轴可见，安装失败有具体原因。
- [ ] 尺寸、位置、角度和连接在保存重载后保持一致。
- [ ] 控制绑定、关节方向、限位与联动实际生效。
- [ ] 加长手臂、改变轮距和移动配重产生可观察的差异。
- [ ] 试跑失败后能快速复位并回编辑，作品不丢失。
- [ ] 自制组件可保存、复用、拆开修改，实例不会意外互相覆盖。
- [ ] 小规模玩家测试中，记录是否独立完成首个作品、能否解释失败原因、是否主动造第二版。
- [ ] 冒险验证中，观察是否产生临场判断、改装重试和探索下一区域的意愿。
